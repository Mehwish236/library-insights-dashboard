# Library Insights Website

A responsive library analytics dashboard built with plain HTML, CSS, and JavaScript. It runs in Chrome directly and requires **no MySQL, Node.js, or package installation**.

## Run on Windows
1. Download and extract this ZIP.
2. Open the extracted folder.
3. Double-click `index.html`. Chrome or your default browser will open the website.

Optional: open the folder in VS Code. If you have the Live Server extension, right-click `index.html` and choose **Open with Live Server**.

## Features
- KPI cards for books, loans, active members, and open loans
- Monthly borrowing chart and genre distribution
- Most borrowed books and branch activity
- Searchable collection, member activity, and loan status views
- CSV export
- Responsive desktop and mobile layout

## Data
All names and records are fictional. Metrics are calculated from data embedded in `script.js`. This is a front-end portfolio demo, not a live database-backed library system.

## Files
- `index.html` — page structure
- `styles.css` — layout and visual design
- `script.js` — demo data, calculations, search, navigation, and CSV export
